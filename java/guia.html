    assertThrows(StockInsuficienteException.class,

Un proyecto Spring Boot es un proyecto Maven: la misma carpeta src/main/java, el mismo pom.xml con dependencias. mvn test en start sale en rojo con dos fallas; el ejercicio es dejarlo en verde. @Test y @BeforeEach son anotaciones, la primera que ven antes de @RestController.

Un commit es una foto del proyecto con un mensaje. target/ va al .gitignore porque Maven lo vuelve a generar. Desde esta noche, cada clase termina con un commit: si algo se rompe, git diff muestra qué cambió y git restore Archivo.java lo devuelve a la última foto. En el trabajo, el mismo repositorio vive en GitHub o GitLab: git clone, git pull, git push y un pull request para que otro revise.
